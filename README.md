# 日野のすがた｜ダッシュボード（プロトタイプ）

滋賀県日野町の統計資料「統計でわかる！日野のすがた」の統計表の数値を CSV に転記し、指標の札とグラフで表示する試作のページです。日野町の公式のページではありません。

画面は1つの HTML（`index.html`）で、`data/` の CSV をブラウザで読んで描きます。色と表記は、日野町データポータルの共通の決まり（hino-portal の DESIGN.md。デジタル庁「ダッシュボードデザインの実践ガイドブック」による）に従います。

## 画面の内容

1. 主な指標（9枚の札）
   * 出生数、高齢化率、社会増減、1世帯あたりの人員、外国籍住民の登録数、観光入込客数、可燃ごみの量（1人1日あたり）、日野駅の乗降客数、経常収支比率の9つです。値は CSV から計算します。
   * 各札には、題、出典と時点、主の値、比べる相手の表、小さな折れ線（札の値の系列）、推移のグラフへのリンクを置きます。
2. 比べる相手と増減
   * 前年（国勢調査の指標は前回の調査）の値を並べ、増減を ▲（増）・▼（減）・＝（同じ）と文言で示します。増減に色は付けません。指標の良し悪しの向きは付けません。
   * 町の計画や財政状況資料集に比べる値があるものは、その値を資料の名前とページを添えて並べます（下の「比べる相手の出典」）。計画の目標と単位が違うものは、札の主の値を目標と同じ単位にし、もとの単位の値は補助の行に残します。計算した値には式を書きます。
   * 比べる値が無いものは、同じ CSV にある関連する数（死亡数と自然増減、転入と転出、人口と世帯数、国籍別の内訳）を並べます。
3. 計算のしかた
   * 1人あたりの可燃ごみの年間の量は、資料の「1人当り（kg）」をそのまま使います。1人1日あたりの g は、年間の kg をその年度の日数で割り、1,000 を掛けて計算します。
   * 1日平均（観光・鉄道）は、年間の数をその年（暦年）または年度の日数で割って計算します。日数は、平年（365日）か閏年（366日）かをプログラムで判定します。
4. 推移のグラフ（27種）
   * 系列が2つ以上のグラフは、ポータル共通の区別の色（5色）を順に当てます。系列が1つだけのグラフは、ポータルの藍で描きます。折れ線は点の形も系列ごとに変えます。国籍別の外国人登録者数は6系列あるので、国籍ごとに同じ目盛りのグラフに分けます。
5. 自動巡回・前後の移動・埋め込み
   * 全グラフを5秒ごとに切り替える表示、「前の統計」「次の統計」のボタン、`?embed=true` による埋め込みができます。自動巡回は、グラフをクリックすると止まります。
6. スマートフォンとキーボード
   * 狭い画面では札を1列に並べます。キーボードで操作したときのフォーカスの枠と、`prefers-reduced-motion`（動きを減らす設定）に対応しています。

## 比べる相手の出典

指標の札の比べる相手は、次の町の公開資料で確かめた値だけを書きます（DESIGN.md ADR-2、hino-portal DESIGN.md 6.2）。

| 指標 | 比べる相手 | 資料とページ |
|---|---|---|
| 高齢化率（令和2年国勢調査） | 全国 28.0%、滋賀県 25.8%、県内19市町の中で4番目に高い | 第9期日野町高齢者福祉計画・介護保険事業計画（令和6年3月） p.9「高齢化率の県内比較（令和２年）」 |
| 経常収支比率（令和6年度） | 全国平均 93.8%、滋賀県平均 92.5%、類似団体内順位 30位/37団体 | 令和6年度財政状況資料集「財政比較分析表」（財政構造の弾力性） |
| 観光入込客数 | 基準値 740,100人（令和元年度）、目標 777,000人（令和7年度）・815,000人（令和12年度） | 第6次日野町総合計画 本編 第3部 基本計画 分野⑨〜㉑（04.pdf） p.12、分野⑭ 観光振興 |
| 可燃ごみの量（1人1日あたり） | 基準値 495g（令和元年度）、目標 474g（令和7年度）・457g（令和12年度） | 第6次日野町総合計画 本編 第3部 基本計画 分野⑨〜㉑（04.pdf） p.24、分野⑳ 循環型社会 |
| 日野駅の乗降客数 | 現状値 312,948人/年（令和4年度）、目標 328,000人/年（令和10年度） | 日野町地域公共交通計画（令和6年3月・令和8年3月改訂） p.42「表15 計画の評価指標と目標値」 |

日野のすがたの「可燃物1人当り」と総合計画の「一日一人あたり可燃ごみ量」で、可燃ごみの範囲など定義が同じかは、資料で確かめられません。札にもそのことを書きます。

## 収録データ一覧

資料の目次の順に、27種のデータを CSV で `data/` に置いています。

### 1. 位置・地勢・気象
* 地目別面積（`hino_land_area.csv`）：田、畑、宅地、林山などの面積推移
* 気象概況（`hino_weather.csv`）：月別平均気温・降水量

### 2. 人口
* 人口・世帯数（`hino_population.csv`）：総人口（男女別）および世帯数の推移
* 人口動態（`hino_vital_stats.csv`）：出生・死亡・自然増加、転入・転出・社会増加の推移
* 外国人登録者数（`hino_foreigners.csv`）：国籍別（ブラジル、フィリピン、中国、韓国・朝鮮、ペルー、その他）の登録者数推移
* 産業区分別就業者数（`hino_industry.csv`）：第一次〜第三次産業における就業者数の推移
* 年齢3区分別人口（`hino_age.csv`）：年少・生産年齢・老年人口の構成と高齢化率（％）の推移

### 3. 産業
* 観光客入込数（`hino_tourism.csv`）：日帰り・宿泊別の観光客数の動向
* 工業の推移（`hino_industry_trend.csv`）：工業事業所数および従業者数の推移

### 4. 農林業
* 経営耕地面積（`hino_farming_area.csv`）：田、畑、樹園地の面積推移
* 農地転用状況（`hino_farmland_conversion.csv`）：住宅用地や駐車場などへの転用面積（㎡）推移

### 5. 運輸・交通
* 近江鉄道日野駅乗降客数（`hino_railway.csv`）：日野駅の年間乗降客数の推移
* 町営バス利用状況（`hino_bus.csv`）：定期・定期外利用者数の推移
* 交通事故発生状況（`hino_traffic_accident.csv`）：町内における交通事故件数の推移

### 6. 水道・通信・消費
* 上水道給水状況（`hino_water_supply.csv`）：給水人口と年間総配水量の推移
* 公共下水道整備状況（`hino_sewerage.csv`）：下水道の普及率と水洗化率の推移
* ごみ投入量（`hino_garbage.csv`）：可燃物・不燃物の投入量、および公式統計に基づく1人あたり排出量（kg）
* たばこ消費量（`hino_tobacco.csv`）：町内のたばこ年間消費量（千本）の推移

### 7. 社会保障
* 国民健康保険（`hino_nhis.csv`）：国保被保険者数と加入率の推移
* 後期高齢者医療（`hino_latter_elderly.csv`）：受給者数・給付件数・1人あたり費用額の推移
* 介護保険（被保険者）（`hino_nursing_care.csv`）：第1号被保険者数（前期・後期別）の推移
* 要介護認定者数（`hino_care_certification.csv`）：原典から転記後に掲載予定
* 保育所・認定こども園（`hino_childcare.csv`）：定員および在籍人員の推移

### 8. 保健衛生
* 三大疾病別死亡数（`hino_diseases.csv`）：がん・心疾患・脳血管疾患による死亡数推移

### 9. 教育・文化
* 図書館の利用状況（`hino_library.csv`）：図書館の来館者数と利用冊数の推移
* 文化施設入館者数（`hino_cultural_facilities.csv`）：商人館・ふるさと館・感応館の入館者数推移

### 10. 財政
* 決算分析指数（`hino_finance_index.csv`）：経常収支比率などの健全化指標

### 11. 治安・消防
* 火災・救急出動（`hino_fire_ambulance.csv`）：火災発生件数と救急車出動件数

出典：[日野町ホームページ「統計でわかる！日野のすがた」](https://www.town.shiga-hino.lg.jp/0000007518.html)

## 外部のサイトへの埋め込み

ほかのサイトに iframe で埋め込めます。URL の末尾に `?embed=true` を付けると、共通の見出し・指標の札・フッターを出さずに、グラフだけを表示します。

    <iframe 
        src="https://kken78.github.io/hino-dashboard/?embed=true#population" 
        width="100%" 
        height="500" 
        style="border:none; background:transparent;" 
        scrolling="no">
    </iframe>

※ `#population` の部分を `#tourism` などに変更すると、最初から指定したグラフを開いた状態で表示できます。

## データの更新

* 令和7年（2025年）国勢調査：人口・世帯・年齢・産業別就業者などの指標は、5年ごとの国勢調査の値で、いまは令和2年（2020年）がいちばん新しい値です。令和7年の調査の結果が公表されたら、`hino_population.csv`・`hino_age.csv`・`hino_industry.csv` などを差し替えます。各札の出典の行に時点を書いています。
* 町の業務・決算の統計：出生・社会増減・ごみ・鉄道・財政などは毎年の値で、いちばん新しい令和6年・令和6年度の値を使っています。

## データの直しと追加の記録（プロトタイプ第2版）

「統計でわかる！日野のすがた2025」の各統計表と全部の CSV を突き合わせ、次のことを行いました。

* ごみ投入量の列：前の版は1人あたりの排出量を画面で概算していましたが、資料に「1人当り（kg）」の値が載っているので、その値を使う形にしました（可燃物・不燃物の投入量、し尿量の列も足しました）。
* 人口動態：自然増加と社会増加（転入 − 転出）の列を足し、指標の札に使いました。
* 年齢3区分別人口：資料の構成比（％）を高齢化率の列として足しました。
* 後期高齢者医療とたばこ消費量の2種を足しました。要介護認定者数は、原典から転記したあとに載せます。
* そのほか、表記の誤りを直しました。



## 免責事項

* データの正確さ：このリポジトリの CSV は、公開されている PDF から文字を取り出して作ったもので、読み取りや転記の誤りを含むことがあります。正確な数値が要るときは、日野町ホームページの元の資料（PDF）を確かめてください。
* 位置づけ：このページは日野町の公式のシステムではなく、日野町 政策参与が個人として作った試作です。予告なく内容を変えたり、公開をやめたりすることがあります。

## 共通の部品

`index.html` の共通の見出し・分野のナビ・ページの一覧・フッター（`<!-- portal-shared:… -->` で囲んだ部分）は、[hino-portal](https://github.com/kken78/hino-portal) の `shared/` の正本の写しです（DESIGN.md ADR-1）。正本と同じかと文字の大きさ（hino-portal DESIGN.md 5.2、DESIGN.md ADR-3）は、GitHub Actions（`.github/workflows/check-shared.yml`）が `python3 hino-portal/shared/check.py --fonts index.html` で確かめ、幅 360px と 1024px での文字の実寸と横のはみ出しを `node hino-portal/shared/check_mobile.mjs index.html`（Playwright が要る。置き方は hino-portal の shared/README.md）で確かめます。

## 町のページの巡回

毎月1日の朝（JST）に、GitHub Actions（`.github/workflows/watch.yml`）が町の「統計でわかる！日野のすがた」のページを巡回し、見つけたものを Issue にします。道具は `tools/watch.py`（標準ライブラリだけ。取得は1秒に1件以内）、見るページは `data/watch.json`、知っている資料とページの更新日は `data/watch.tsv` です。

| 見つけるもの | 確かめ方 |
|---|---|
| 新しい資料 | 見るページに、`data/watch.tsv` に無い PDF のリンクがある |
| 資料が取れない | `data/watch.tsv` で status が「使用」の PDF（画面の指標の出典（2025年版））が、ページからリンクされなくなったか、404 などで取れない |
| ページの更新 | ページの「更新日」が `data/watch.tsv` の updated と違う |

巡回は見つけるだけで、`data/` のデータと画面は変えません。Issue の本文の「次にやること」に従って転記し、`data/watch.tsv` に行を足すか updated を直します（直さないと次の月にまた Issue ができます）。巡回そのものに失敗したときは、ワークフローが失敗して「巡回に失敗した」Issue ができます。同じ内容の Issue が開いていれば作りません。手元では `python3 tools/watch.py` で確かめられます。定期実行は60日間コミットが無いと止まるため、`.github/workflows/keepalive.yml` が毎月1日に有効化し直します。
